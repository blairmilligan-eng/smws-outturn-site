SMWS Code 42: Tobermory

Distillery behind Society cask numbers 42.x

SMWS code 42 is Tobermory, in the Islands region. It is an operating distillery, founded in 1798. Any Society bottling numbered 42.x (for example 42.1, 42.42) is a single cask from Tobermory.

About Tobermory

“Tobermory distillery is an Island single malt Scotch whisky and gin distillery located on the Hebridean island of Mull, Scotland in the town of Tobermory”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 42.403 means cask 403 from distillery 42. That distillery is Tobermory, in Islands. More on Tobermory at Wikipedia.
