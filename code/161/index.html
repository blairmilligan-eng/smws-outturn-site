SMWS Code 161: Nc'nean Distillery

Distillery behind Society cask numbers 161.x

SMWS code 161 is Nc'nean Distillery, in the Scotland region. It is an operating distillery, founded in 2017. Any Society bottling numbered 161.x (for example 161.1, 161.42) is a single cask from Nc'nean Distillery.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 161.403 means cask 403 from distillery 161. That distillery is Nc'nean Distillery, in Scotland. More on Nc'nean Distillery at Wikipedia.
