SMWS Code 64: Mannochmore

Distillery behind Society cask numbers 64.x

SMWS code 64 is Mannochmore, in the Speyside region. It is an operating distillery, founded in 1971. Any Society bottling numbered 64.x (for example 64.1, 64.42) is a single cask from Mannochmore.

About Mannochmore

Born in 1971 near Elgin, sharing a fence with Glenlossie, Mannochmore makes a light, clean Speyside spirit, and one gloriously strange footnote: Loch Dhu, the jet-black whisky of the 1990s that drinkers still argue about to this day. Diageo's.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 64.403 means cask 403 from distillery 64. That distillery is Mannochmore, in Speyside. More on Mannochmore at Wikipedia.
