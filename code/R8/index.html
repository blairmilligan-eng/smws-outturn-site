SMWS Code R8: Compañía Licorera de Nicaragua (Flor de Caña)

Distillery behind Society cask numbers R8.x

SMWS code R8 is Compañía Licorera de Nicaragua (Flor de Caña), in the Nicaragua region. Any Society bottling numbered R8.x (for example R8.1, R8.42) is a single cask from Compañía Licorera de Nicaragua (Flor de Caña).

The Scotch Malt Whisky Society bottles single casks under numeric codes instead of distillery names. Code R8 is Compañía Licorera de Nicaragua (Flor de Caña), a Nicaragua distillery. Read more about Compañía Licorera de Nicaragua (Flor de Caña) on Wikipedia.
