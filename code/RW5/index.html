SMWS Code RW5: MGP

Distillery behind Society cask numbers RW5.x

SMWS code RW5 is MGP, in Indiana, USA. It is an operating distillery, founded in 2007. Any Society bottling numbered RW5.x (for example RW5.1, RW5.42) is a single cask from MGP.

About MGP

“High West Distillery is a manufacturer of distilled spirits located in Park City, Utah, United States. It is the first legally licensed distillery in Utah since the end of the American Prohibition.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading RW5.403 means cask 403 from distillery RW5. That distillery is MGP, in Indiana, USA. More on MGP at Wikipedia.
