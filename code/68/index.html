SMWS Code 68: Blair Athol

Distillery behind Society cask numbers 68.x

SMWS code 68 is Blair Athol, in the Highland region. It is an operating distillery, founded in 1798. Any Society bottling numbered 68.x (for example 68.1, 68.42) is a single cask from Blair Athol.
