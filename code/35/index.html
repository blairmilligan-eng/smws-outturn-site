SMWS Code 35: Glen Moray

Distillery behind Society cask numbers 35.x

SMWS code 35 is Glen Moray, in the Speyside region. It is an operating distillery, founded in 1897. Any Society bottling numbered 35.x (for example 35.1, 35.42) is a single cask from Glen Moray.

About Glen Moray

On the banks of the Lossie in Elgin, Glen Moray has poured out honest, easy-going Speyside since 1897, the malt that has welcomed more newcomers into whisky than almost any other, and for the gentlest of prices. Unshowy, and quietly adventurous with its casks. La Martiniquaise own it.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 35.403 means cask 403 from distillery 35. That distillery is Glen Moray, in Speyside. More on Glen Moray at Wikipedia.
