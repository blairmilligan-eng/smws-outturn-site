SMWS Code GN1: Glasgow Distillery Company

Distillery behind Society cask numbers GN1.x

SMWS code GN1 is Glasgow Distillery Company, in the Lowland region. Any Society bottling numbered GN1.x (for example GN1.1, GN1.42) is a single cask from Glasgow Distillery Company.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading GN1.403 means cask 403 from distillery GN1. That distillery is Glasgow Distillery Company, in Lowland. More on Glasgow Distillery Company at Wikipedia.
