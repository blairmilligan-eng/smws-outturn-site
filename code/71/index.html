SMWS Code 71: Glenburgie

Distillery behind Society cask numbers 71.x

SMWS code 71 is Glenburgie, in the Speyside region. It is an operating distillery, founded in 1810. Any Society bottling numbered 71.x (for example 71.1, 71.42) is a single cask from Glenburgie.

About Glenburgie

“Glenburgie distillery, is Speyside single malt Scotch whisky distillery located near Alves, Moray, Scotland.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 71.403 means cask 403 from distillery 71. That distillery is Glenburgie, in Speyside. More on Glenburgie at Wikipedia.
