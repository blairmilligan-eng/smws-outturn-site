SMWS Code 69: Glen Albyn

Distillery behind Society cask numbers 69.x

SMWS code 69 is Glen Albyn, in the Highland region. Any Society bottling numbered 69.x (for example 69.1, 69.42) is a single cask from Glen Albyn.

  • DistilleryGlen Albyn
  • RegionHighland
  • StatusStatus unknown

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 69.403 means cask 403 from distillery 69. That distillery is Glen Albyn, in Highland. More on Glen Albyn at Wikipedia.
