SMWS Code 53: Caol Ila

Distillery behind Society cask numbers 53.x

SMWS code 53 is Caol Ila, in the Islay region. It is an operating distillery, founded in 1846. Any Society bottling numbered 53.x (for example 53.1, 53.42) is a single cask from Caol Ila.

About Caol Ila

Hidden in a cove above Port Askaig, gazing across the churning Sound of Islay to the Paps of Jura, Caol Ila (1846) is the island's largest distillery and the quiet engine-room of Johnnie Walker. On its own, though, it is a beauty: oily and cool, olive brine and lemon and a soft grey smoke. Diageo's.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 53.403 means cask 403 from distillery 53. That distillery is Caol Ila, in Islay. More on Caol Ila at Wikipedia.
