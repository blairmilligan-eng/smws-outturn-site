SMWS Code 53: Caol Ila

Distillery behind Society cask numbers 53.x

SMWS code 53 is Caol Ila, in the Islay region. Any Society bottling numbered 53.x (for example 53.1, 53.42) is a single cask from Caol Ila.

The Scotch Malt Whisky Society bottles single casks under numeric codes instead of distillery names. Code 53 is Caol Ila, a Islay distillery. Read more about Caol Ila on Wikipedia.
