SMWS Code 149: Ardnamurchan

Distillery behind Society cask numbers 149.x

SMWS code 149 is Ardnamurchan, in the Highland region. Any Society bottling numbered 149.x (for example 149.1, 149.42) is a single cask from Ardnamurchan.

The Scotch Malt Whisky Society bottles single casks under numeric codes instead of distillery names. Code 149 is Ardnamurchan, a Highland distillery. Read more about Ardnamurchan on Wikipedia.
