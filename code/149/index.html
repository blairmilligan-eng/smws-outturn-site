SMWS Code 149: Ardnamurchan

Distillery behind Society cask numbers 149.x

SMWS code 149 is Ardnamurchan, in the Highland region. It is an operating distillery, founded in 2014. Any Society bottling numbered 149.x (for example 149.1, 149.42) is a single cask from Ardnamurchan.

About Ardnamurchan

“Ardnamurchan distillery is a Scotch whisky distillery on the Ardnamurchan peninsula of Lochaber in the Highlands, Scotland. The distillery is considered one of the remotest distilleries in Scotland and takes its name from the peninsula.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 149.403 means cask 403 from distillery 149. That distillery is Ardnamurchan, in Highland. More on Ardnamurchan at Wikipedia.
