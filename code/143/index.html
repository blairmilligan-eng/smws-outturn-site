SMWS Code 143: Copperworks Distilling Co.

Distillery behind Society cask numbers 143.x

SMWS code 143 is Copperworks Distilling Co., in the Washington, USA region. Any Society bottling numbered 143.x (for example 143.1, 143.42) is a single cask from Copperworks Distilling Co..

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 143.403 means cask 403 from distillery 143. That distillery is Copperworks Distilling Co., in Washington, USA. More on Copperworks Distilling Co. at Wikipedia.
