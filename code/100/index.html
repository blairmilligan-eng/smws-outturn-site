SMWS Code 100: Strathmill

Distillery behind Society cask numbers 100.x

SMWS code 100 is Strathmill, in the Speyside region. Any Society bottling numbered 100.x (for example 100.1, 100.42) is a single cask from Strathmill.

  • DistilleryStrathmill
  • RegionSpeyside
  • StatusStatus unknown

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 100.403 means cask 403 from distillery 100. That distillery is Strathmill, in Speyside. More on Strathmill at Wikipedia.
