SMWS Code 100: Strathmill

Distillery behind Society cask numbers 100.x

SMWS code 100 is Strathmill, in the Speyside region. It is an operating distillery, founded in 1891. Any Society bottling numbered 100.x (for example 100.1, 100.42) is a single cask from Strathmill.

About Strathmill

At Keith since 1891, Strathmill pours a light, grassy Speysider that quietly holds up J&B without ever chasing the limelight. Diageo's, and seldom seen alone.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 100.403 means cask 403 from distillery 100. That distillery is Strathmill, in Speyside. More on Strathmill at Wikipedia.
