SMWS Code B4: FEW Spirits

Distillery behind Society cask numbers B4.x

SMWS code B4 is FEW Spirits, in Illinois, USA. It is an operating distillery. Any Society bottling numbered B4.x (for example B4.1, B4.42) is a single cask from FEW Spirits.

About FEW Spirits

“Scotch whisky is distilled from water, cereals and yeast. It must be matured for three years or more before bottling, and bottled at 40% or more alcohol by volume.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading B4.403 means cask 403 from distillery B4. That distillery is FEW Spirits, in Illinois, USA. More on FEW Spirits at Wikipedia.
