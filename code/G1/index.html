SMWS Code G1: North British

Distillery behind Society cask numbers G1.x

SMWS code G1 is North British, in the Lowland region. It is an operating distillery, founded in 1885. Any Society bottling numbered G1.x (for example G1.1, G1.42) is a single cask from North British.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading G1.403 means cask 403 from distillery G1. That distillery is North British, in Lowland. More on North British at Wikipedia.
