SMWS Code 9: Glen Grant

Distillery behind Society cask numbers 9.x

SMWS code 9 is Glen Grant, in the Speyside region. It is an operating distillery, founded in 1840. Any Society bottling numbered 9.x (for example 9.1, 9.42) is a single cask from Glen Grant.

About Glen Grant

“Glen Grant distillery was founded in 1840 in Rothes, Speyside, and produces single malt Scotch whisky.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 9.403 means cask 403 from distillery 9. That distillery is Glen Grant, in Speyside. More on Glen Grant at Wikipedia.
