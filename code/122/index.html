SMWS Code 122: Loch Lomond (Croftengea)

Distillery behind Society cask numbers 122.x

SMWS code 122 is Loch Lomond (Croftengea), in the Highland region. It is an operating distillery, founded in 1966. Any Society bottling numbered 122.x (for example 122.1, 122.42) is a single cask from Loch Lomond (Croftengea).

About Loch Lomond (Croftengea)

“Loch Lomond is a Highland Single Malt Scotch whisky distillery in Alexandria, Scotland, near Loch Lomond.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 122.403 means cask 403 from distillery 122. That distillery is Loch Lomond (Croftengea), in Highland. More on Loch Lomond (Croftengea) at Wikipedia.
