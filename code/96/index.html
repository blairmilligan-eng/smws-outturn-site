SMWS Code 96: GlenDronach

Distillery behind Society cask numbers 96.x

SMWS code 96 is GlenDronach, in the Highland region. It is an operating distillery, founded in 1826. Any Society bottling numbered 96.x (for example 96.1, 96.42) is a single cask from GlenDronach.
