SMWS Code 38: Caperdonich

Distillery behind Society cask numbers 38.x

SMWS code 38 is Caperdonich, in the Speyside region. It is a closed distillery (ceased production in 2002). Any Society bottling numbered 38.x (for example 38.1, 38.42) is a single cask from Caperdonich.
