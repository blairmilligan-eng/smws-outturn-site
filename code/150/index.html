SMWS Code 150: West Cork Distillers

Distillery behind Society cask numbers 150.x

SMWS code 150 is West Cork Distillers, in Ireland. Any Society bottling numbered 150.x (for example 150.1, 150.42) is a single cask from West Cork Distillers.

  • DistilleryWest Cork Distillers
  • RegionIreland

  • LocationIreland

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 150.403 means cask 403 from distillery 150. That distillery is West Cork Distillers, in Ireland. More on West Cork Distillers at Wikipedia.
