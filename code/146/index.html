SMWS Code 146: Cotswolds

Distillery behind Society cask numbers 146.x

SMWS code 146 is Cotswolds, in England. It is an operating distillery, founded in 2014. Any Society bottling numbered 146.x (for example 146.1, 146.42) is a single cask from Cotswolds.

About Cotswolds

“Cotswolds Distillery is an English distillery producing single malt whisky, gin and other spirits. It is located in Stourton, near Shipston-on-Stour, in the Cotswolds region of England.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 146.403 means cask 403 from distillery 146. That distillery is Cotswolds, in England. More on Cotswolds at Wikipedia.
