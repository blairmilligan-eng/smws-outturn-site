SMWS Code 58: Strathisla

Distillery behind Society cask numbers 58.x

SMWS code 58 is Strathisla, in the Speyside region. It is an operating distillery, founded in 1786. Any Society bottling numbered 58.x (for example 58.1, 58.42) is a single cask from Strathisla.

About Strathisla

At Keith since 1786, by its own account the oldest working distillery in the Highlands, Strathisla is almost impossibly pretty, twin pagoda roofs and a waterwheel mirrored in the River Isla. It is the beating heart of Chivas Regal, and the place looks like a whisky postcard come to life. Pernod Ricard's.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 58.403 means cask 403 from distillery 58. That distillery is Strathisla, in Speyside. More on Strathisla at Wikipedia.
