SMWS Code R2: Demerara Distillers (El Dorado)

Distillery behind Society cask numbers R2.x

SMWS code R2 is Demerara Distillers (El Dorado), in the Guyana region. It is an operating distillery. Any Society bottling numbered R2.x (for example R2.1, R2.42) is a single cask from Demerara Distillers (El Dorado).
