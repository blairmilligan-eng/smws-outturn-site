SMWS Code R2: Demerara Distillers (El Dorado)

Distillery behind Society cask numbers R2.x

SMWS code R2 is Demerara Distillers (El Dorado), in Guyana. It is an operating distillery. Any Society bottling numbered R2.x (for example R2.1, R2.42) is a single cask from Demerara Distillers (El Dorado).

About Demerara Distillers (El Dorado)

“Demerara Distillers Ltd. (DDL) is a Guyanese distillery known for the El Dorado Rum brand.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading R2.403 means cask 403 from distillery R2. That distillery is Demerara Distillers (El Dorado), in Guyana. More on Demerara Distillers (El Dorado) at Wikipedia.
