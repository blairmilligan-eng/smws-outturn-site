SMWS Code 162: Isle of Raasay

Distillery behind Society cask numbers 162.x

SMWS code 162 is Isle of Raasay, in the Scotland region. It is an operating distillery, founded in 2016. Any Society bottling numbered 162.x (for example 162.1, 162.42) is a single cask from Isle of Raasay.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 162.403 means cask 403 from distillery 162. That distillery is Isle of Raasay, in Scotland. More on Isle of Raasay at Wikipedia.
