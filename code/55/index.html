SMWS Code 55: Royal Brackla

Distillery behind Society cask numbers 55.x

SMWS code 55 is Royal Brackla, in the Highland region. It is an operating distillery, founded in 1812. Any Society bottling numbered 55.x (for example 55.1, 55.42) is a single cask from Royal Brackla.
