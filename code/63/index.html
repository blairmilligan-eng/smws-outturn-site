SMWS Code 63: Glentauchers

Distillery behind Society cask numbers 63.x

SMWS code 63 is Glentauchers, in the Speyside region. It is an operating distillery, founded in 1897. Any Society bottling numbered 63.x (for example 63.1, 63.42) is a single cask from Glentauchers.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 63.403 means cask 403 from distillery 63. That distillery is Glentauchers, in Speyside. More on Glentauchers at Wikipedia.
