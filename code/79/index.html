SMWS Code 79: Deanston

Distillery behind Society cask numbers 79.x

SMWS code 79 is Deanston, in the Highland region. It is an operating distillery, founded in 1966. Any Society bottling numbered 79.x (for example 79.1, 79.42) is a single cask from Deanston.
