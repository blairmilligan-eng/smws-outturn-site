SMWS Code 128: Penderyn

Distillery behind Society cask numbers 128.x

SMWS code 128 is Penderyn, in Wales. It is an operating distillery, founded in 1900. Any Society bottling numbered 128.x (for example 128.1, 128.42) is a single cask from Penderyn.
