SMWS Code 88: Speyburn

Distillery behind Society cask numbers 88.x

SMWS code 88 is Speyburn, in the Speyside region. It is an operating distillery, founded in 1897. Any Society bottling numbered 88.x (for example 88.1, 88.42) is a single cask from Speyburn.

About Speyburn

“Speyburn distillery is a Speyside Scottish whisky distillery, in Rothes, Moray, Scotland.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 88.403 means cask 403 from distillery 88. That distillery is Speyburn, in Speyside. More on Speyburn at Wikipedia.
