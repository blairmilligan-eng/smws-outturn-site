SMWS Code 77: Glen Ord

Distillery behind Society cask numbers 77.x

SMWS code 77 is Glen Ord, in the Highland region. It is an operating distillery, founded in 1838. Any Society bottling numbered 77.x (for example 77.1, 77.42) is a single cask from Glen Ord.

About Glen Ord

“Glen Ord distillery is a whisky distillery in the Scottish Highlands.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 77.403 means cask 403 from distillery 77. That distillery is Glen Ord, in Highland. More on Glen Ord at Wikipedia.
