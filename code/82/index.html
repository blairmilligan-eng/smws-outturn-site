SMWS Code 82: Glencadam

Distillery behind Society cask numbers 82.x

SMWS code 82 is Glencadam, in the Highland region. It is an operating distillery, founded in 1825. Any Society bottling numbered 82.x (for example 82.1, 82.42) is a single cask from Glencadam.

About Glencadam

In Brechin, in the gentle farmland of Angus, Glencadam has distilled since 1825 and today stands as the last working distillery in a town that once had several. Owned by Angus Dundee, it keeps a low profile and a devoted following. The house style is soft, creamy and fruity, an elegant, almost delicate Highland malt with none of the coastal edge of its neighbours to the north. Long treated as a blending malt, it has increasingly won admirers under its own name, and a single cask shows off exactly what those admirers prize: a clean, orchard-fruit sweetness with a silky, cream-and-vanilla heart.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 82.403 means cask 403 from distillery 82. That distillery is Glencadam, in Highland. More on Glencadam at Wikipedia.
