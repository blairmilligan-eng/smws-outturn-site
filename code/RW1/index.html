SMWS Code RW1: FEW Spirits

Distillery behind Society cask numbers RW1.x

SMWS code RW1 is FEW Spirits, in Illinois, USA. It is an operating distillery. Any Society bottling numbered RW1.x (for example RW1.1, RW1.42) is a single cask from FEW Spirits.

About FEW Spirits

“Scotch whisky is distilled from water, cereals and yeast. It must be matured for three years or more before bottling, and bottled at 40% or more alcohol by volume.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading RW1.403 means cask 403 from distillery RW1. That distillery is FEW Spirits, in Illinois, USA. More on FEW Spirits at Wikipedia.
