SMWS Code G7: Girvan

Distillery behind Society cask numbers G7.x

SMWS code G7 is Girvan, in the Lowland region. Any Society bottling numbered G7.x (for example G7.1, G7.42) is a single cask from Girvan.

  • DistilleryGirvan
  • RegionLowland
  • StatusStatus unknown

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading G7.403 means cask 403 from distillery G7. That distillery is Girvan, in Lowland. More on Girvan at Wikipedia.
