SMWS Code 66: Ardmore

Distillery behind Society cask numbers 66.x

SMWS code 66 is Ardmore, in the Highland region. It is an operating distillery, founded in 1898. Any Society bottling numbered 66.x (for example 66.1, 66.42) is a single cask from Ardmore.

About Ardmore

“Ardmore distillery is a single malt Scotch whisky distillery, located in the village of Kennethmont, Scotland. The distillery is owned and operated by Suntory Global Spirits, a subsidiary of Suntory Holdings of Osaka, Japan.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 66.403 means cask 403 from distillery 66. That distillery is Ardmore, in Highland. More on Ardmore at Wikipedia.

Which distillery is SMWS code 66?
