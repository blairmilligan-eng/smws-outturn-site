SMWS Code R3: West Indies Rum

Distillery behind Society cask numbers R3.x

SMWS code R3 is West Indies Rum, in the Barbados region. It is an operating distillery, founded in 1893. Any Society bottling numbered R3.x (for example R3.1, R3.42) is a single cask from West Indies Rum.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading R3.403 means cask 403 from distillery R3. That distillery is West Indies Rum, in Barbados. More on West Indies Rum at Wikipedia.
