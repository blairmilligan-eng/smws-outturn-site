SMWS Code 48: Balmenach

Distillery behind Society cask numbers 48.x

SMWS code 48 is Balmenach, in the Speyside region. It is an operating distillery, founded in 1824. Any Society bottling numbered 48.x (for example 48.1, 48.42) is a single cask from Balmenach.

About Balmenach

Above the village of Cromdale, where the Spey runs cold and the Jacobites met defeat in 1690, Balmenach has quietly made whisky since 1824, one of the oldest distilleries in all of Speyside. It keeps to the old ways and the old character, a robust, weighty, faintly meaty make that blenders have long prized and that rewards the patient. These days the same site also turns out Caorunn gin, but the single malt remains a throwback, a big-boned Speysider with none of the modern polish. Under Inver House it works far from the tourist trail, which suits a distillery that has always let the spirit speak for itself.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 48.403 means cask 403 from distillery 48. That distillery is Balmenach, in Speyside. More on Balmenach at Wikipedia.
