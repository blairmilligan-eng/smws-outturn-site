SMWS Code 48: Balmenach

Distillery behind Society cask numbers 48.x

SMWS code 48 is Balmenach, in the Speyside region. Any Society bottling numbered 48.x (for example 48.1, 48.42) is a single cask from Balmenach.

The Scotch Malt Whisky Society bottles single casks under numeric codes instead of distillery names. Code 48 is Balmenach, a Speyside distillery. Read more about Balmenach on Wikipedia.
