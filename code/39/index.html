SMWS Code 39: Linkwood

Distillery behind Society cask numbers 39.x

SMWS code 39 is Linkwood, in the Speyside region. It is an operating distillery, founded in 1821. Any Society bottling numbered 39.x (for example 39.1, 39.42) is a single cask from Linkwood.

About Linkwood

Near Elgin, founded in 1821, Linkwood makes a whisky of such delicate, blossom-and-fruit precision that blenders treasure it, and legend has it the stillmen once refused to sweep away the cobwebs, for fear of disturbing whatever kept the character so perfectly the same. Diageo's, and rarely bottled alone.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 39.403 means cask 403 from distillery 39. That distillery is Linkwood, in Speyside. More on Linkwood at Wikipedia.
