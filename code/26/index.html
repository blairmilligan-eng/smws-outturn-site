SMWS Code 26: Clynelish

Distillery behind Society cask numbers 26.x

SMWS code 26 is Clynelish, in the Highland region. It is an operating distillery, founded in 1967. Any Society bottling numbered 26.x (for example 26.1, 26.42) is a single cask from Clynelish.
