SMWS Code A2: Domaine Laguille

Distillery behind Society cask numbers A2.x

SMWS code A2 is Domaine Laguille, in France. Any Society bottling numbered A2.x (for example A2.1, A2.42) is a single cask from Domaine Laguille.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading A2.403 means cask 403 from distillery A2. That distillery is Domaine Laguille, in France. More on Domaine Laguille at Wikipedia.
