SMWS Code 95: Auchroisk

Distillery behind Society cask numbers 95.x

SMWS code 95 is Auchroisk, in the Speyside region. It is an operating distillery, founded in 1974. Any Society bottling numbered 95.x (for example 95.1, 95.42) is a single cask from Auchroisk.

About Auchroisk

“Auchroisk distillery is a whisky distillery in Banffshire, Speyside, Scotland.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 95.403 means cask 403 from distillery 95. That distillery is Auchroisk, in Speyside. More on Auchroisk at Wikipedia.
