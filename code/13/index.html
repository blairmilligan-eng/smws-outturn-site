SMWS Code 13: Dalmore

Distillery behind Society cask numbers 13.x

SMWS code 13 is Dalmore, in the Highland region. It is an operating distillery, founded in 1839. Any Society bottling numbered 13.x (for example 13.1, 13.42) is a single cask from Dalmore.
