SMWS Code 115: Knockdhu (AnCnoc)

Distillery behind Society cask numbers 115.x

SMWS code 115 is Knockdhu (AnCnoc), in the Speyside region. It is an operating distillery, founded in 1894. Any Society bottling numbered 115.x (for example 115.1, 115.42) is a single cask from Knockdhu (AnCnoc).
