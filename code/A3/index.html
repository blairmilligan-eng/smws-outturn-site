SMWS Code A3: J. Goudoulin (Veuve Goudoulin)

Distillery behind Society cask numbers A3.x

SMWS code A3 is J. Goudoulin (Veuve Goudoulin), in France. Any Society bottling numbered A3.x (for example A3.1, A3.42) is a single cask from J. Goudoulin (Veuve Goudoulin).
