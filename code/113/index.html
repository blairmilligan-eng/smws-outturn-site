SMWS Code 113: Braeval (Braes of Glenlivet)

Distillery behind Society cask numbers 113.x

SMWS code 113 is Braeval (Braes of Glenlivet), in the Speyside region. It is an operating distillery, founded in 1973. Any Society bottling numbered 113.x (for example 113.1, 113.42) is a single cask from Braeval (Braes of Glenlivet).

About Braeval (Braes of Glenlivet)

High in the hills above Glenlivet, at Chapeltown in remote Banffshire, Braeval is one of the highest distilleries in Scotland, built in 1973 in country so out of the way it has always run with the smallest of crews. It was raised as Braes of Glenlivet and took the name Braeval later. Owned by Chivas Brothers, it exists chiefly to feed blends, and its make is light, clean and grassy, the very definition of a modern Speyside workhorse. There is a purity to a whisky born this high in the glen, and a single cask lets that mountain-fresh character finally speak on its own.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 113.403 means cask 403 from distillery 113. That distillery is Braeval (Braes of Glenlivet), in Speyside. More on Braeval (Braes of Glenlivet) at Wikipedia.
