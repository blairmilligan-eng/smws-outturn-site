SMWS Code RW7: Journeyman Distillery

Distillery behind Society cask numbers RW7.x

SMWS code RW7 is Journeyman Distillery, in Michigan, USA. Any Society bottling numbered RW7.x (for example RW7.1, RW7.42) is a single cask from Journeyman Distillery.
