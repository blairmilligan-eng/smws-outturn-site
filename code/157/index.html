SMWS Code 157: Distillerie de Warenghem

Distillery behind Society cask numbers 157.x

SMWS code 157 is Distillerie de Warenghem, in the France region. Any Society bottling numbered 157.x (for example 157.1, 157.42) is a single cask from Distillerie de Warenghem.

  • DistilleryDistillerie de Warenghem
  • RegionFrance
  • StatusStatus unknown

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 157.403 means cask 403 from distillery 157. That distillery is Distillerie de Warenghem, in France. More on Distillerie de Warenghem at Wikipedia.
