SMWS Code 33: Ardbeg

Distillery behind Society cask numbers 33.x

SMWS code 33 is Ardbeg, in the Islay region. It is an operating distillery, founded in 1794. Any Society bottling numbered 33.x (for example 33.1, 33.42) is a single cask from Ardbeg.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 33.403 means cask 403 from distillery 33. That distillery is Ardbeg, in Islay. More on Ardbeg at Wikipedia.
