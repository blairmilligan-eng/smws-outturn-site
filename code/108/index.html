SMWS Code 108: Allt-a-Bhainne

Distillery behind Society cask numbers 108.x

SMWS code 108 is Allt-a-Bhainne, in the Speyside region. It is an operating distillery, founded in 1975. Any Society bottling numbered 108.x (for example 108.1, 108.42) is a single cask from Allt-a-Bhainne.

About Allt-a-Bhainne

“Allt-A-Bhainne distillery is a Scotch whisky distillery in the Speyside Region of Scotland. It is located just down the road from the well-known whisky town of Dufftown.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 108.403 means cask 403 from distillery 108. That distillery is Allt-a-Bhainne, in Speyside. More on Allt-a-Bhainne at Wikipedia.
