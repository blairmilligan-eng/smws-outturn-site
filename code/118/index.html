SMWS Code 118: Cooley / Connemara (Peated)

Distillery behind Society cask numbers 118.x

SMWS code 118 is Cooley / Connemara (Peated), in the Ireland region. Any Society bottling numbered 118.x (for example 118.1, 118.42) is a single cask from Cooley / Connemara (Peated).

The Scotch Malt Whisky Society bottles single casks under numeric codes instead of distillery names. Code 118 is Cooley / Connemara (Peated), a Ireland distillery. Read more about Cooley / Connemara (Peated) on Wikipedia.
