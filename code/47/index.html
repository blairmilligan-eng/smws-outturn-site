SMWS Code 47: Benromach

Distillery behind Society cask numbers 47.x

SMWS code 47 is Benromach, in the Speyside region. Any Society bottling numbered 47.x (for example 47.1, 47.42) is a single cask from Benromach.

  • DistilleryBenromach
  • RegionSpeyside
  • StatusStatus unknown

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 47.403 means cask 403 from distillery 47. That distillery is Benromach, in Speyside. More on Benromach at Wikipedia.
