SMWS Code 168: InchDairnie Distillery (KinGlassie)

Distillery behind Society cask numbers 168.x

SMWS code 168 is InchDairnie Distillery (KinGlassie), in the Lowland region. It is an operating distillery, founded in 2015. Any Society bottling numbered 168.x (for example 168.1, 168.42) is a single cask from InchDairnie Distillery (KinGlassie).

About InchDairnie Distillery (KinGlassie)

“InchDairnie distillery is a Lowland single malt Scotch whisky and Rye Whisky distillery in Glenrothes, Scotland.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 168.403 means cask 403 from distillery 168. That distillery is InchDairnie Distillery (KinGlassie), in Lowland. More on InchDairnie Distillery (KinGlassie) at Wikipedia.
