SMWS Code 44: Craigellachie

Distillery behind Society cask numbers 44.x

SMWS code 44 is Craigellachie, in the Speyside region. It is an operating distillery, founded in 1891. Any Society bottling numbered 44.x (for example 44.1, 44.42) is a single cask from Craigellachie.

About Craigellachie

High above the Spey since 1891, Craigellachie keeps the old ways on purpose. Its worm-tub condensers, coiled in cold water outside, breed a heavier, sulphury, struck-match muscle that traditionalists prize like a secret. Part of the Dewar's family (Bacardi).

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 44.403 means cask 403 from distillery 44. That distillery is Craigellachie, in Speyside. More on Craigellachie at Wikipedia.
