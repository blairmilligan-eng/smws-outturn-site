SMWS Code GN4: Boatyard Distillery

Distillery behind Society cask numbers GN4.x

SMWS code GN4 is Boatyard Distillery, in the Northern Ireland region. Any Society bottling numbered GN4.x (for example GN4.1, GN4.42) is a single cask from Boatyard Distillery.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading GN4.403 means cask 403 from distillery GN4. That distillery is Boatyard Distillery, in Northern Ireland. More on Boatyard Distillery at Wikipedia.
