SMWS Code 6: Macduff

Distillery behind Society cask numbers 6.x

SMWS code 6 is Macduff, in the Highland region. It is an operating distillery, founded in 1962. Any Society bottling numbered 6.x (for example 6.1, 6.42) is a single cask from Macduff.

About Macduff

“The Macduff distillery is a single malt Scotch whisky distillery in Macduff, Aberdeenshire in the Highland whisky producing area of Scotland.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 6.403 means cask 403 from distillery 6. That distillery is Macduff, in Highland. More on Macduff at Wikipedia.
