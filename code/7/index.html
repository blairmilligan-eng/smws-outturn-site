SMWS Code 7: Longmorn

Distillery behind Society cask numbers 7.x

SMWS code 7 is Longmorn, in the Speyside region. It is an operating distillery, founded in 1894. Any Society bottling numbered 7.x (for example 7.1, 7.42) is a single cask from Longmorn.

About Longmorn

Founded near Elgin in 1893, Longmorn is the trade's worst-kept secret, a distiller's distillery hoarded by blenders for a spirit of uncommon richness: oily, waxy, brimming with orchard and stone fruit. It rarely appears under its own name, which makes an independent cask feel like being let in on something. Pernod Ricard's.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 7.403 means cask 403 from distillery 7. That distillery is Longmorn, in Speyside. More on Longmorn at Wikipedia.
