SMWS Code G15: Loch Lomond (Rhosdhu)

Distillery behind Society cask numbers G15.x

SMWS code G15 is Loch Lomond (Rhosdhu), in the Highland region. It is an operating distillery, founded in 1966. Any Society bottling numbered G15.x (for example G15.1, G15.42) is a single cask from Loch Lomond (Rhosdhu).

About Loch Lomond (Rhosdhu)

“Loch Lomond is a Highland Single Malt Scotch whisky distillery in Alexandria, Scotland, near Loch Lomond.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading G15.403 means cask 403 from distillery G15. That distillery is Loch Lomond (Rhosdhu), in Highland. More on Loch Lomond (Rhosdhu) at Wikipedia.
