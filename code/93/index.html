SMWS Code 93: Glen Scotia

Distillery behind Society cask numbers 93.x

SMWS code 93 is Glen Scotia, in the Campbeltown region. It is an operating distillery, founded in 1832. Any Society bottling numbered 93.x (for example 93.1, 93.42) is a single cask from Glen Scotia.

About Glen Scotia

“Glen Scotia, historically known as The Scotia or Old Scotia is a distillery that produces single malt Scotch whisky. It was founded in 1832 and is one of three distilleries left in Campbeltown, the smallest whisky region.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 93.403 means cask 403 from distillery 93. That distillery is Glen Scotia, in Campbeltown. More on Glen Scotia at Wikipedia.
