SMWS Code 72: Miltonduff

Distillery behind Society cask numbers 72.x

SMWS code 72 is Miltonduff, in the Speyside region. It is an operating distillery, founded in 1824. Any Society bottling numbered 72.x (for example 72.1, 72.42) is a single cask from Miltonduff.

About Miltonduff

“Miltonduff distillery is a Scotch whisky distillery located in Miltonduff six miles south-west of Elgin in the whisky region of Speyside.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 72.403 means cask 403 from distillery 72. That distillery is Miltonduff, in Speyside. More on Miltonduff at Wikipedia.
