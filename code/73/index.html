SMWS Code 73: Aultmore

Distillery behind Society cask numbers 73.x

SMWS code 73 is Aultmore, in the Speyside region. Any Society bottling numbered 73.x (for example 73.1, 73.42) is a single cask from Aultmore.

The Scotch Malt Whisky Society bottles single casks under numeric codes instead of distillery names. Code 73 is Aultmore, a Speyside distillery. Read more about Aultmore on Wikipedia.
