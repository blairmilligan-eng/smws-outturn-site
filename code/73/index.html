SMWS Code 73: Aultmore

Distillery behind Society cask numbers 73.x

SMWS code 73 is Aultmore, in the Speyside region. It is an operating distillery, founded in 1896. Any Society bottling numbered 73.x (for example 73.1, 73.42) is a single cask from Aultmore.

About Aultmore

Out on the lonely Foggie Moss near Keith, Aultmore (1895) was long a hidden malt, spoken of by locals and blenders and seldom by anyone else, prized for a clean, grassy, spring-water freshness. One of the Dewar's family (Bacardi).

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 73.403 means cask 403 from distillery 73. That distillery is Aultmore, in Speyside. More on Aultmore at Wikipedia.
