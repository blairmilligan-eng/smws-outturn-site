SMWS Code 10: Bunnahabhain

Distillery behind Society cask numbers 10.x

SMWS code 10 is Bunnahabhain, in the Islay region. Any Society bottling numbered 10.x (for example 10.1, 10.42) is a single cask from Bunnahabhain.

The Scotch Malt Whisky Society bottles single casks under numeric codes instead of distillery names. Code 10 is Bunnahabhain, a Islay distillery. Read more about Bunnahabhain on Wikipedia.
