SMWS Code 5: Auchentoshan

Distillery behind Society cask numbers 5.x

SMWS code 5 is Auchentoshan, in the Lowland region. It is an operating distillery, founded in 1823. Any Society bottling numbered 5.x (for example 5.1, 5.42) is a single cask from Auchentoshan.

About Auchentoshan

“Auchentoshan distillery is a Lowland single malt Scotch whisky distillery in Dalmuir, Scotland.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 5.403 means cask 403 from distillery 5. That distillery is Auchentoshan, in Lowland. More on Auchentoshan at Wikipedia.
