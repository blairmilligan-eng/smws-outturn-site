SMWS Code 135: Loch Lomond

Distillery behind Society cask numbers 135.x

SMWS code 135 is Loch Lomond, in the Highland region. It is an operating distillery, founded in 1966. Any Society bottling numbered 135.x (for example 135.1, 135.42) is a single cask from Loch Lomond.

About Loch Lomond

“Loch Lomond is a Highland Single Malt Scotch whisky distillery in Alexandria, Scotland, near Loch Lomond.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 135.403 means cask 403 from distillery 135. That distillery is Loch Lomond, in Highland. More on Loch Lomond at Wikipedia.
