SMWS Code 1: Glenfarclas

Distillery behind Society cask numbers 1.x

SMWS code 1 is Glenfarclas, in the Speyside region. It is an operating distillery, founded in 1836. Any Society bottling numbered 1.x (for example 1.1, 1.42) is a single cask from Glenfarclas.

About Glenfarclas

“Glenfarclas distillery is a Speyside whisky distillery in Ballindalloch, Scotland. The distillery is owned and run by the Grant family.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 1.403 means cask 403 from distillery 1. That distillery is Glenfarclas, in Speyside. More on Glenfarclas at Wikipedia.
