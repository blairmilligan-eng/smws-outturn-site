SMWS Code 50: Bladnoch

Distillery behind Society cask numbers 50.x

SMWS code 50 is Bladnoch, in the Lowland region. It is an operating distillery, founded in 1817. Any Society bottling numbered 50.x (for example 50.1, 50.42) is a single cask from Bladnoch.

About Bladnoch

At Wigtown, in the green Galloway lowlands, stands Bladnoch, the most southerly distillery in Scotland. Born in 1817, silenced and stirred back to life more than once, most recently rescued in 2015 by Australian David Prior, it makes a soft, floral, gently sweet Lowland spirit, a survivor with a light touch.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 50.403 means cask 403 from distillery 50. That distillery is Bladnoch, in Lowland. More on Bladnoch at Wikipedia.
