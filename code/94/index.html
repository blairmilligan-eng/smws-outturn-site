SMWS Code 94: Fettercairn

Distillery behind Society cask numbers 94.x

SMWS code 94 is Fettercairn, in the Highland region. It is an operating distillery, founded in 1824. Any Society bottling numbered 94.x (for example 94.1, 94.42) is a single cask from Fettercairn.

About Fettercairn

“Fettercairn distillery is a Highland single malt Scotch whisky distillery in Fettercairn. Situated under the Grampian foothills in the Howe of Mearns, Fettercairn town’s name is loosely based on the phrase "the foot of the mountain".”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 94.403 means cask 403 from distillery 94. That distillery is Fettercairn, in Highland. More on Fettercairn at Wikipedia.
