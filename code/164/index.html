SMWS Code 164: Penderyn (double distilled)

Distillery behind Society cask numbers 164.x

SMWS code 164 is Penderyn (double distilled), in Wales. It is an operating distillery, founded in 1900. Any Society bottling numbered 164.x (for example 164.1, 164.42) is a single cask from Penderyn (double distilled).
