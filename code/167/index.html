SMWS Code 167: Clydeside Distillery

Distillery behind Society cask numbers 167.x

SMWS code 167 is Clydeside Distillery, in the Scotland region. It is an operating distillery, founded in 2017. Any Society bottling numbered 167.x (for example 167.1, 167.42) is a single cask from Clydeside Distillery.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 167.403 means cask 403 from distillery 167. That distillery is Clydeside Distillery, in Scotland. More on Clydeside Distillery at Wikipedia.
