SMWS Code 142: Breuckelen Distilling

Distillery behind Society cask numbers 142.x

SMWS code 142 is Breuckelen Distilling, in New York, USA. Any Society bottling numbered 142.x (for example 142.1, 142.42) is a single cask from Breuckelen Distilling.
