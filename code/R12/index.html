SMWS Code R12: Travellers

Distillery behind Society cask numbers R12.x

SMWS code R12 is Travellers, in the Belize region. It is an operating distillery, founded in 1953. Any Society bottling numbered R12.x (for example R12.1, R12.42) is a single cask from Travellers.

About Travellers

“Travellers Liquors Limited is a distiller based in Belize. The company produces a variety of different liquors, specializing in aged rum.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading R12.403 means cask 403 from distillery R12. That distillery is Travellers, in Belize. More on Travellers at Wikipedia.
