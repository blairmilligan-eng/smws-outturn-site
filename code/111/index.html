SMWS Code 111: Lagavulin

Distillery behind Society cask numbers 111.x

SMWS code 111 is Lagavulin, in the Islay region. It is an operating distillery, founded in 1816. Any Society bottling numbered 111.x (for example 111.1, 111.42) is a single cask from Lagavulin.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 111.403 means cask 403 from distillery 111. That distillery is Lagavulin, in Islay. More on Lagavulin at Wikipedia.
