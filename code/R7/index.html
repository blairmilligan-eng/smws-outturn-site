SMWS Code R7: Hampden

Distillery behind Society cask numbers R7.x

SMWS code R7 is Hampden, in the Jamaica region. Any Society bottling numbered R7.x (for example R7.1, R7.42) is a single cask from Hampden.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading R7.403 means cask 403 from distillery R7. That distillery is Hampden, in Jamaica. More on Hampden at Wikipedia.
