SMWS Code 140: Balcones

Distillery behind Society cask numbers 140.x

SMWS code 140 is Balcones, in Texas, USA. Any Society bottling numbered 140.x (for example 140.1, 140.42) is a single cask from Balcones.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 140.403 means cask 403 from distillery 140. That distillery is Balcones, in Texas, USA. More on Balcones at Wikipedia.
