SMWS Code 91: Dufftown

Distillery behind Society cask numbers 91.x

SMWS code 91 is Dufftown, in the Speyside region. It is an operating distillery, founded in 1895. Any Society bottling numbered 91.x (for example 91.1, 91.42) is a single cask from Dufftown.

About Dufftown

“Dufftown distillery is a Scotch whisky distillery in Dufftown, Moray, Scotland.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 91.403 means cask 403 from distillery 91. That distillery is Dufftown, in Speyside. More on Dufftown at Wikipedia.
