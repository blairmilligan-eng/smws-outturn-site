SMWS Code 119: Yamazaki

Distillery behind Society cask numbers 119.x

SMWS code 119 is Yamazaki, in the Japan region. Any Society bottling numbered 119.x (for example 119.1, 119.42) is a single cask from Yamazaki.

  • DistilleryYamazaki
  • RegionJapan
  • StatusStatus unknown

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 119.403 means cask 403 from distillery 119. That distillery is Yamazaki, in Japan. More on Yamazaki at Wikipedia.
