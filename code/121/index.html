SMWS Code 121: Isle of Arran

Distillery behind Society cask numbers 121.x

SMWS code 121 is Isle of Arran, in the Islands region. It is an operating distillery. Any Society bottling numbered 121.x (for example 121.1, 121.42) is a single cask from Isle of Arran.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 121.403 means cask 403 from distillery 121. That distillery is Isle of Arran, in Islands. More on Isle of Arran at Wikipedia.
