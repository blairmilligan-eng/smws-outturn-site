SMWS Code 19: Glen Garioch

Distillery behind Society cask numbers 19.x

SMWS code 19 is Glen Garioch, in the Highland region. It is an operating distillery, founded in 1797. Any Society bottling numbered 19.x (for example 19.1, 19.42) is a single cask from Glen Garioch.

About Glen Garioch

“Glen Garioch distillery is a Highland single malt Scotch whisky distillery in Oldmeldrum, Aberdeenshire, Scotland. It is one of the oldest whisky distilleries in Scotland, dating back to 1797.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 19.403 means cask 403 from distillery 19. That distillery is Glen Garioch, in Highland. More on Glen Garioch at Wikipedia.
