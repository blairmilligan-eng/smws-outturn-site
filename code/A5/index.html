SMWS Code A5: Chateau de Laubade

Distillery behind Society cask numbers A5.x

SMWS code A5 is Chateau de Laubade, in France. Any Society bottling numbered A5.x (for example A5.1, A5.42) is a single cask from Chateau de Laubade.
