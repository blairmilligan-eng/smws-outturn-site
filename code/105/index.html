SMWS Code 105: Tormore

Distillery behind Society cask numbers 105.x

SMWS code 105 is Tormore, in the Speyside region. It is an operating distillery, founded in 1958. Any Society bottling numbered 105.x (for example 105.1, 105.42) is a single cask from Tormore.

About Tormore

“Tormore distillery is a Speyside single malt Scotch whisky distillery located approximately 1 km south of the River Spey. Its water source is the Allt an Torra Mhoir Burn.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 105.403 means cask 403 from distillery 105. That distillery is Tormore, in Speyside. More on Tormore at Wikipedia.
