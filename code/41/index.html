SMWS Code 41: Dailuaine

Distillery behind Society cask numbers 41.x

SMWS code 41 is Dailuaine, in the Speyside region. Any Society bottling numbered 41.x (for example 41.1, 41.42) is a single cask from Dailuaine.

The Scotch Malt Whisky Society bottles single casks under numeric codes instead of distillery names. Code 41 is Dailuaine, a Speyside distillery. Read more about Dailuaine on Wikipedia.
