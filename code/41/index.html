SMWS Code 41: Dailuaine

Distillery behind Society cask numbers 41.x

SMWS code 41 is Dailuaine, in the Speyside region. It is an operating distillery, founded in 1851. Any Society bottling numbered 41.x (for example 41.1, 41.42) is a single cask from Dailuaine.

About Dailuaine

Tucked at Carron in the folds of Speyside since 1852, Dailuaine is a big, brawny, sometimes meaty malt that has long lent muscle to Johnnie Walker. Diageo seldom lets it out under its own name, so a single cask is a rare handshake with a distillery most people drink without ever knowing.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 41.403 means cask 403 from distillery 41. That distillery is Dailuaine, in Speyside. More on Dailuaine at Wikipedia.
