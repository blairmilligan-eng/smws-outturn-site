SMWS Code 85: Glen Elgin

Distillery behind Society cask numbers 85.x

SMWS code 85 is Glen Elgin, in the Speyside region. It is an operating distillery, founded in 1898. Any Society bottling numbered 85.x (for example 85.1, 85.42) is a single cask from Glen Elgin.
