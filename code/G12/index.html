SMWS Code G12: Nikka Coffey Malt

Distillery behind Society cask numbers G12.x

SMWS code G12 is Nikka Coffey Malt, in Japan. Any Society bottling numbered G12.x (for example G12.1, G12.42) is a single cask from Nikka Coffey Malt.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading G12.403 means cask 403 from distillery G12. That distillery is Nikka Coffey Malt, in Japan. More on Nikka Coffey Malt at Wikipedia.
