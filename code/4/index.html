SMWS Code 4: Highland Park

Distillery behind Society cask numbers 4.x

SMWS code 4 is Highland Park, in the Islands region. It is an operating distillery, founded in 1788. Any Society bottling numbered 4.x (for example 4.1, 4.42) is a single cask from Highland Park.

About Highland Park

Far north on Orkney, above Kirkwall and scoured by Atlantic wind, Highland Park has made whisky since 1798. It is among the last to still malt its own barley on the floor by hand and kiln it over island peat, heather-rich and aromatic, quite unlike the mainland's. The result is a beautifully poised malt where wood-smoke and honey hold hands. Edrington own it; the Norsemen, in spirit, still haunt it.

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 4.403 means cask 403 from distillery 4. That distillery is Highland Park, in Islands. More on Highland Park at Wikipedia.
