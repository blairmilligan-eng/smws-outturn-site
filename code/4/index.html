SMWS Code 4: Highland Park

Distillery behind Society cask numbers 4.x

SMWS code 4 is Highland Park, in the Islands region. Any Society bottling numbered 4.x (for example 4.1, 4.42) is a single cask from Highland Park.

The Scotch Malt Whisky Society bottles single casks under numeric codes instead of distillery names. Code 4 is Highland Park, a Islands distillery. Read more about Highland Park on Wikipedia.
