SMWS Code 28: Tullibardine

Distillery behind Society cask numbers 28.x

SMWS code 28 is Tullibardine, in the Highland region. It is an operating distillery, founded in 1949. Any Society bottling numbered 28.x (for example 28.1, 28.42) is a single cask from Tullibardine.

About Tullibardine

“Tullibardine distillery is a Scottish distillery since 1949, producing a single malt whisky. The whisky distillery is located in Blackford, Perth and Kinross, close to the Ochil Hills and the Danny Burn, their main water sources.”From Wikipedia, CC BY-SA

The Scotch Malt Whisky Society bottles single casks under numeric codes rather than distillery names, so a label reading 28.403 means cask 403 from distillery 28. That distillery is Tullibardine, in Highland. More on Tullibardine at Wikipedia.
