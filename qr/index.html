SMWS Distillery Codes

Which distillery is behind each SMWS number

Just the number before the dot is enough

The Scotch Malt Whisky Society (SMWS) bottles single casks under a code such as 4.403 rather than a distillery name. The number before the dot is the distillery; the number after is the individual cask. This independent site decodes every SMWS code to its distillery and region — each on its own page — and tracks the monthly Outturn.

Frequently asked questions

How do SMWS cask codes work?
The Scotch Malt Whisky Society labels each single-cask bottling with a number like 4.403. The number before the dot identifies the distillery; the number after is the individual cask. SMWS does not print distillery names, so this page maps every code to its distillery.
What do Scotch Malt Whisky Society numbers mean?
Every Scotch Malt Whisky Society bottling is numbered rather than named. The number before the dot identifies the distillery and the number after it identifies the cask.
What does the number after the dot mean?
It is the sequential cask number for that distillery. So 4.403 is the 403rd cask the Society has bottled from distillery 4 (Highland Park).
Why doesn't SMWS just print the distillery name?
The Society buys casks under agreements that usually don't permit naming the distillery, so it uses a code instead. The distilleries themselves are an open secret in the whisky community.
Are these distillery mappings official?
No. They are community-sourced and maintained independently. Most are well established, but some codes are disputed. See the methodology page and please report any corrections.
What is an SMWS Outturn?
The Outturn is the Society's regular release of new single-cask bottlings. This site shows the current Outturn and decodes each bottle's distillery.
